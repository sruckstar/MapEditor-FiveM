Здесь лежат карты, сохранённые на сервере.

Эта папка должна существовать до первого сохранения: SAVE_RESOURCE_FILE открывает файл на
запись и НЕ создаёт недостающие каталоги — без папки запись просто возвращает false. Ради этого
здесь и лежит README: пустой каталог не переживает ни git, ни zip.

Каталог карт — index.json, его пишет сам сервер при старте. Файлы рядом — общие карты, те, что
видит каждый игрок и на запись которых нужно право mapeditor.publish.

players/<ник>/ — личные карты игроков: то, что они сохранили пунктом «Save Local», и их
автосейвы. Каждую такую карту видит и может загрузить только её владелец. Папки заводятся сами
при первом сохранении; имя папки — ник, но принадлежность считается по идентификатору license,
так что смена ника карты не отбирает.

Для игроков это единственное место, где их работа вообще хранится: клиент FiveM не может
записать файл к себе на диск.

При обновлении ресурса (git pull, rsync, распаковка архива поверх) эту папку НЕ ЗАТИРАЙТЕ:
index.json, карты и players/ — это данные владельца сервера и его игроков, а не часть поставки.
